Remove Nth Node From End

Use two pointers and a dummy node to remove a node in one pass.

Step 1 of 1
How It Works

A dummy node before the head makes removal safe even when the head is the answer.

Key insight

Move fast n nodes ahead. Then move both pointers together. When fast reaches the last node, slow is immediately before the node to remove.

  1. 1 Create dummy → head; start both pointers at dummy.
  2. 2 Advance fast by n nodes.
  3. 3 Move both pointers until fast.next is null.
  4. 4 Skip slow.next to unlink the target node.

Time: O(L)   Space: O(1)
